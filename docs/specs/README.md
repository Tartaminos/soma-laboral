# Especificações de implementação

## Objetivo

Este diretório contém as especificações técnicas próprias do projeto `soma-laboral`.

As especificações históricas usadas para construir o repositório-base permanecem no template de origem e não fazem parte da documentação operacional deste cliente.

## Regra de precedência

Em caso de divergência, aplicar esta ordem:

1. `docs/ARCHITECTURE.md`;
2. `docs/CODING_GUIDELINES.md`;
3. spec da implementação da Soma Laboral;
4. documentação técnica correspondente às versões instaladas;
5. convenções existentes no módulo afetado.
